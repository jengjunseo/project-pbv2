# Context

- Users want PB as an instant transfer helper based on slot numbers 0-99.
- Ease of use is prioritized over strong security.
- Files are limited to 5MB.
- Text and files should disappear from normal access after 10 minutes.
- Render was abandoned because cold starts hurt the experience.
- Vercel is the target deployment platform.
- PB is not a database, message board, chat app, or cloud drive.
- The core product is a short-lived pocket where one number holds one temporary payload.
