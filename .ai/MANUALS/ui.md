# UI

## Principles
- Mobile first.
- Minimal and direct.
- No login or profile settings.
- Avoid excessive decoration.
- Keep the transfer warning visible.

## Home
- App title `PB`.
- Short explanation.
- Numeric slot input.
- Open button.
- Safety warning.

## Slot
- Slot number, e.g. `PB #17`.
- Back action.
- Current status: empty, saved, or expired.
- Countdown while saved.
- Text editor.
- File upload area.
- Save button.
- Clear button.
- Attached file name, size, and open/download action.

## Error Messages
Errors should be short and actionable, such as "Slot id must be an integer between 0 and 99."
